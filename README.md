# VLM-Document-AI
VLM (Vision-Language Model) 문서 AI 기술은 페이지를 이미지로 입력받아서 텍스트, 구조, 의미를 함께 분석하는 방향으로 발전하고 있다.

이 레파지토리에서는 최근 VLM 논문을 요약하고, 코드로 구현하고, 구현 시의 시행착오들을 기록한다. 

연구 관점에서의 접근 뿐만 아니라, 실사용 관점에서의 한계점을 케이스 별로 분석하며, 개선점을 도출한 뒤, 추가 검증을 기록 한다.
